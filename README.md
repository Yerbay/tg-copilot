# TG Copilot — подсказки для переписки

Бот читает выбранные личные чаты пользователя в Telegram и WhatsApp (только из его белого списка),
принимает скриншоты переписок из любых приложений и голосовые, присылает варианты ответа, разборы
и напоминания и отвечает на вопросы в свободной форме.
**Отправляет сообщения всегда сам пользователь**: Telegram и WhatsApp в коде только читаются,
бот пишет только пользователям бота.

Многопользовательский: до `MAX_USERS` человек, у каждого свои контакты, подключения и история.
Если человек есть и в Telegram, и в WhatsApp, это один контакт: переписка объединяется по времени
с метками `TG`/`WA`/`SS` (скриншот), карточка одна.

## Установка (Python 3.13+, Node.js 20+)

```bash
cd tg-copilot
python -m venv .venv
# Windows:  .venv\Scripts\activate
# Linux/Mac: source .venv/bin/activate
pip install -r requirements.txt
copy .env.example .env      # Linux/Mac: cp .env.example .env
cd wa && npm install && cd ..   # мост WhatsApp
```

Заполните `.env`:
- `TG_API_ID`, `TG_API_HASH` — на https://my.telegram.org → API development tools (любой аккаунт);
- `BOT_TOKEN` — @BotFather → `/newbot`;
- `ADMIN_ID` — ваш Telegram ID (узнать: @userinfobot);
- `LLM_API_KEY` — ключ DeepSeek (https://platform.deepseek.com → API keys);
- `STT_API_KEY` — ключ Gemini для распознавания голосовых (https://aistudio.google.com/apikey);
- `MAX_USERS`, `USER_DAILY_LIMIT` — сколько человек и сколько запросов к ИИ в день на каждого.

## Запуск

```bash
python main.py
```
Откройте бота и нажмите **Start** — бот пришлёт «Копилот запущен». Подключения (Telegram, WhatsApp)
делаются прямо в боте: «подключи вотсап, мой номер …», «подключи телеграм» или кнопка «🔌 Подключения».

- **WhatsApp** — по коду привязки: бот присылает код, его вводят в WhatsApp → Настройки →
  Связанные устройства → Привязка устройства → «Связать по номеру телефона». Бот подключается как
  связанное устройство: не показывает «в сети», не отмечает прочитанным. Старую переписку не выгружает —
  история контакта начинается с момента добавления в белый список.
- **Telegram** — по QR, который присылает бот; сканировать с телефона (Настройки → Устройства →
  Подключить устройство), показав QR на другом экране. Облачный пароль, если есть, бот спросит и сразу
  удалит сообщение с ним. Telegram иногда завершает такие сеансы на основных аккаунтах —
  надёжнее подключать второй аккаунт. Запасной путь для администратора: `python login_qr.py [id]` в терминале.
- **Скриншоты** — подключать не нужно: просто присылайте.

## Пользователи

- Новый человек пишет боту → администратору приходит «🙋 Запрос доступа» с кнопками «Пустить» / «Отказать».
- После одобрения бот спрашивает, с кем человек переписывается (девушки/парни — от этого зависят
  подсказки), и предлагает подключения.
- `/users` (администратор) — список, что подключено, контакты, запросы за сегодня; кнопки блокировки и удаления.
- `/delete_me` — пользователь удаляет все свои данные; бот завершает сеанс Telegram и отвязывает WhatsApp.
- Каждый видит только свои данные; кнопки с чужими контактами не работают.

## Как пользоваться

Пишите боту **обычным языком** — он сам решит, что сделать (модель вызывает нужные инструменты):

- «добавь Анну, её вотсап 8 701 123 45 67», «её телеграм @anna — это тоже Анна»
- «что ответить Анне?», «дай варианты посмешнее», «сделай второй короче»
- «она стала отвечать коротко, что не так?», «как позвать её в субботу?»
- «вот мой черновик для Анны: …»
- «запомни, что Анна работает дизайнером»
- «кому я давно не отвечал?», «сделай вечерний разбор»
- «убери Марию из списка» — удаление только после кнопки подтверждения

Бот не может написать кому-либо от вашего имени — такого инструмента у него нет.
Сам он пишет вам: **когда она пишет** — через `DEBOUNCE_SECONDS` варианты ответа с кнопками
«Ещё», «Короче», «С юмором», «Теплее» (если вы ответили раньше — подсказки не будет);
**каждый вечер в `DAILY_HOUR`** — обновление карточек, разбор ваших ответов за день, напоминания.

Разговор ведёт быстрая модель (`LLM_MODEL`), сложные разборы — умная (`LLM_MODEL_SMART`).

Команды — то же самое коротко, если удобнее:

| Команда | Что делает |
|---|---|
| `/menu` | главное меню |
| `/add @username Имя` | добавить чат Telegram в белый список |
| `/add wa +77011234567 Имя` | добавить чат WhatsApp; то же имя — привязать к уже добавленному человеку |
| `/list` | собеседницы |
| `/suggest Имя` | варианты ответа сейчас |
| `/draft Имя текст` | разбор черновика |
| `/review Имя` | разбор переписки |
| `/all` | консультация по всем |
| `/done` | закончить консультацию |
| `/daily` | вечерний разбор сейчас |
| `/wa` | состояние WhatsApp |

Имя из нескольких слов — в кавычках: `/review "Анна Мария"`.

## Смена LLM

В `.env` поменяйте `LLM_PROVIDER`, `LLM_MODEL`, `LLM_MODEL_SMART`, `LLM_API_KEY` и перезапустите.
`LLM_MODEL` — быстрая модель для подсказок в переписке, `LLM_MODEL_SMART` — для разборов,
консультаций и вечернего отчёта (пусто — та же, что `LLM_MODEL`).
Поддерживаются: `gemini`, `deepseek`, `openai`, `claude`, `ollama` (локально).
Новый провайдер с OpenAI-совместимым API — одна строка в `PROVIDERS` в `llm.py`.

## Промпты

Все тексты для модели — в `prompts.py`. Правьте тон и формат там.

## Безопасность

- `sessions/<id>/tg.session` = полный доступ к Telegram пользователя, `wa-session/<id>/` — к его WhatsApp,
  `copilot_bot.session` — к боту.
  Не выкладывайте, не храните в облаке. Отвязать: Telegram → Настройки → Устройства; WhatsApp → Связанные устройства.
- Сообщения WhatsApp не из белого списка отбрасываются сразу: не сохраняются и не уходят в LLM.
  Сообщения из списка хранятся в `copilot.db` и удаляются вместе с контактом.
- `.env`, `*.session`, `*.db`, `wa-session/` уже в `.gitignore`.
- Переписка уходит выбранному LLM-провайдеру. Для полной приватности — `ollama` на своей машине.

## Перенос на сервер

Скопируйте папку вместе с `.env`, `copilot_bot.session`, `sessions/`, `wa-session/` и `copilot.db`, поставьте зависимости
(`pip install -r requirements.txt`, `npm install` в `wa/`) и запустите
`python main.py` под systemd или в `tmux`. Повторный вход не понадобится.
